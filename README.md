# 🎮 Hangman Game in Python

## 📌 About the Project
Hangman is a simple word-guessing game developed using Python.
The player has to guess a hidden word by entering one letter at a time.

## ✨ Features
- Random word selection
- Hints to help the player
- Maximum 6 incorrect guesses
- Displays correctly guessed letters
- Checks repeated and invalid inputs
- Shows a winning message or game-over message

## 🛠️ Technologies Used
- Python
- Random module

## ▶️ How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   python hangman.py

## 🎯 Objective
The objective is to guess the hidden word before running out of attempts.
